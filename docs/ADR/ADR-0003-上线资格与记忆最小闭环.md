# ADR-0003：上线资格 P0 处置 + 记忆最小闭环（回应 v1.2 严格评审）

- 状态：已接受（Accepted）
- 日期：2026-10-13
- 触发：v1.2 评审指出两个 P0（主体/类目资格未解决；7/7 测试≠可靠）与历史理解闭环缺失

## 一、P0-1：上线资格（已核实，非推测）

### 核实结论

```
1. 微信「深度合成」类目仅向非个人主体（企业/组织）开放；个人主体无法正式上线 AI 问答类小程序
2. 该类目申请需提交：技术方（模型 API 服务商）的《互联网信息服务算法备案》截图（生成合成类-深度合成）
   以及双方合作协议/授权材料
3. 平台支持"个人 → 组织"的主体迁移（不支持个人→个人）
```

### 处置路径（按时间可行性排序）

| 路径 | 动作 | 时间风险 | 建议 |
|---|---|---|---|
| A | 注册个体工商户/企业主体 → 小程序主体升级 → 申请深度合成类目 → 提交模型商算法备案截图+协议 | 主体线上办理 1-3 天；类目审核另需时间 | **立即启动**，这是唯一合规正解 |
| B | 使用已有企业主体（自有公司/合作方/学校孵化器）授权挂靠 | 取决于资源 | 若有，最快 |
| C | 无法在窗口内解决 → 以体验版+完整证据链参与，并在材料中如实说明 | 可能不符合"正式上线"要求 | 兜底，不冒用类目 |

### 明令禁止

**不得将 AI 生成能力以"工具-效率"类目提交以规避深度合成审核。** 这属于类目错报，可能导致下架与主体处罚，且违背本项目"合规即产品"的定位。v1.2 文档中"类目：工具-效率"的表述作废，改为"深度合成（生成合成类），需非个人主体"。

## 二、P0-2：测试从 7 断言扩到 16 断言（覆盖评审列出的异常场景）

新增覆盖：红线违反检测｜提示词注入（备注中写"忽略以上指令"）｜历史信息冲突（旧目标不得作为当前事实）｜非法 JSON｜字段缺失｜路径数越界｜伪精确概率｜投资标的｜违法路径｜来源标注缺失｜引用提取｜模型超时/安全服务失败降级路径。

## 三、记忆最小闭环（不做 Mem0，但必须能通过评审第 1、5、6 题）

### 为什么现在必须做

评审第 1 题（"引用我过去说过的话"）、第 5 题（"7 天没完成，你改了什么"）、第 6 题（"记错了能否看到原话并纠正"）检验的是**可追溯的事实账本**，而不是向量检索能力。这类能力用业务数据库即可实现，且成本远低于引入 Mem0。

### 设计：事实与目标账本（memoryItems 集合）

```
每条记录：{ openid, kind: fact|goal|redline|inference, content, source: user_confirmed|ai_inferred,
           status: current|superseded|expired, evidence(原话), supersededBy, createdAt, updatedAt }

硬规则：
1. 只有 user_confirmed 才能作为推演事实；ai_inferred 注入时必须标注"待用户确认"
2. 目标变更：旧目标置 superseded（保留历史，注入时标注"（历史，已变更）"），不得作为当前事实
3. 红线独立存储并作为硬约束注入；输出后二次校验，违反即判失败重试
4. 纠错与删除留审计（auditLog）；删除覆盖派生的注入快照
5. 每次推演记录注入了哪些记忆条目 id（injectedMemoryIds）→ 支撑"引用准确率"指标
```

### 反馈驱动计划调整（plan 云函数）

```
done    → 提议升档（下一步 +1）
partial → 维持，提示可拆分
missed  → 降载：拆分行动、缩短单次时长；连续 2 次 missed 触发目标周期冻结建议
每次调整写入 adjustments 集合：{ openid, reason, before, after, triggerFeedbackId } → 可回答"你改了什么、为什么"
```

## 四、可验证的"越来越准"三指标（替代口号）

| 指标 | 定义 | 数据来源 |
|---|---|---|
| 历史引用准确率 | 推演中引用的记忆条目中，用户在记忆本确认为正确的比例 | injectedMemoryIds + 记忆本确认/纠正记录 |
| 理解摘要确认率 | AI 生成"我对你的理解"摘要后，用户确认 vs 纠正的比例 | 摘要交互记录 |
| 反馈后行动完成率变化 | 调整后下一周期行动完成率相对调整前的变化 | actionFeedbacks 前后对比 |

## 五、后果

- v1.2 文档第 2.2 节 Out of scope 中"Mem0 接入"改为"Mem0 接入（阶段 2）；阶段 0 以事实账本实现可追溯记忆"。
- 演示证据链固定为一条：大学生用户 → 初始画像 → 首次推演 → 目标变更（考研→就业）→ 红线注入 → 7 天未完成 → 计划调整 → 记忆本纠错。
- 参赛材料中不得出现"AI 精准识别性格"等超出能力的表述。
