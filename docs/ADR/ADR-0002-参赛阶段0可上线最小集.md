# ADR-0002：参赛阶段 0 重定义为「可上线最小集」（范围冻结）

- 状态：已接受（Accepted）
- 日期：2026-10-13
- 决策人：项目负责人（选项 A：参赛优先）

## 背景

大赛要求作品在 2026-07-17 ~ 10-17 提报期内**正式上线**并能在微信内正常运行。v1.1 第 8 节的"阶段 0 = 演示原型，不代表可正式上线"与参赛资格冲突。本 ADR 将阶段 0 重定义为**按可上线标准构建的最小集**，并冻结参赛窗口内的功能范围。

## 范围冻结（2026-10-13 ~ 10-17）

### 包含（Must）

```
1. 最小生活画像：基础情况 + 教育职业 + 目标与顾虑（三组），全字段支持备注
   渐进式：三组填完即可推演；其余模块入口显示"稍后补充"
2. 单主题情景推演：每次 1 个主题，输出 2-3 条路径，
   每条路径含 v1.1 第 3.2 节七要素（描述/成立条件/关键变量/机会代价/风险预警/可验证行动/不确定性说明）
   时间跨度：仅 7 天行动 + 未来 1 年情景；不生成更远的具体断言
3. 7 天行动实验 + 一次结果反馈提交（完成/部分/未做 + 原因）
4. 合规三件套：免责声明（模拟非预测/非投资医疗法律建议）+ 关键事实用户确认流程 + AI 生成内容标识
5. 内容安全：msgSecCheck(输入) + 输出 JSON 校验 + 敏感信息(身份证/手机号)拦截
6. 每日回访（订阅消息，可选功能）：行动到期提醒 + 温和话术（"你给自己定的…"）
7. 探索性自我反思问题（≤5 题）：界面与材料标注"探索性问卷"，结果仅用于个性化行动风格，不宣称性格测评
```

### 明确排除（Out of scope，参赛窗口内不做）

```
- 正式性格量表（BFI-2 等）：授权与心理测量核查无法在窗口内完成 → 阶段 1
- 3/5/10 年推演内容：仅保留"更远时间线的存在说明"，不给具体断言 → 阶段 2-4
- Mem0 接入：业务库为唯一事实来源；记忆层接口预留（memoryPort），数据流与删除链路设计完成即可 → 阶段 2
- 地域外部数据：仅用模型内置知识生成城市级描述并在不确定性说明中标注局限 → 阶段 3
- 语音访谈、平行人生沙盘、社区功能
```

## 验收标准（= 上线门禁）

```
[ ] 微信审核通过并正式发布（10-17 前）
[ ] 新用户 5 分钟内完成三组画像并跑通一次推演
[ ] 每条推演输出包含七要素且通过 JSON 结构校验
[ ] 金样例回归通过（红线：无伪精确概率、无具体投资标的、无违法路径、含免责与不确定性说明）
[ ] 反馈提交链路可用（打卡数据入库）
[ ] v1.1 第 9 节指标的最小子集埋点：首次推演完成率、7 日反馈回流率、纠正画像比例
```

## 后果

- 开发按本范围执行，新增想法一律记录到 backlog，窗口内不加功能。
- 提审类目：工具-效率；名称「MyNext」（注册时以微信公众平台名称检测为准，备选：未来自己、人生沙盘）。
- 赛后按 v1.1 阶段 1-4 路线演进，本 ADR 由 ADR-0003（赛后规划）接替。
