# 演示证据链脚本（4 分钟现场演示用）

> 目的：证明 MyNext 不是"生成一段漂亮人生故事"，而是**能根据历史事实、红线与真实反馈修正建议**。
> 固定一个大学生案例，全程用同一账号，每步都指向可查的数据。

## 演示前置

```
账号：一台真机（演示账号 A）
准备：小程序已登录；云开发环境正常；LLM_API_KEY 已配置
开场话术："接下来 4 分钟，我用同一个学生账号，走一遍他会真实经历的过程。"
```

## 第 1 幕｜建立画像（40 秒）

操作：打开「完善我的画像」，填写三组：

```
基础：小王 / 1995 / 杭州 / 备注：膝盖旧伤不能跑步
教育职业：二本计算机 2027 届 / 应届生，目前在准备考研 / 备注：家里说可以支持一年脱产
目标：毕业后先定方向 / 顾虑：考研还是就业拿不准 / 红线：不接受负债创业
```

看点：**备注字段**立即成为上下文（后续推演会被引用）；**红线**被独立记录。

## 第 2 幕｜第一次推演（60 秒）

操作：进入推演页，主题输入「考研还是直接就业」，生成。

看点：输出是 2-3 条路径，每条都有**成立条件 / 关键变量 / 机会与代价 / 风险预警 / 不确定性 / 7 天可验证行动**；
页面显示「AI生成」标识与免责声明；**没有出现任何成功率数字**。

现场可答评委提问："为什么不用概率？"→ 因为我们没有可核验的校准数据，给数字就是伪精确。

## 第 3 幕｜目标变更（30 秒）——回答评审第 1、6 题

操作：进入「AI 记住了我什么」，添加新目标「毕业后直接就业」。

看点：原目标「考研上岸」自动变为 **历史，已变更**（灰色标签），不再是当前事实；
再次推演时，提示词中旧目标被标注为「（历史，已变更）」。

## 第 4 幕｜红线硬校验（40 秒）——回答评审第 4 题

操作：说明机制并展示测试记录（不依赖模型自觉）：

```
输出层二次校验：若任何路径包含"负债创业"且附近无"排除/不考虑"等否定语义 → 判定失败并重试
自动化证据：tests/golden 第 16、17 条（违反被拦 / 说明性排除不误判）
```

## 第 5 幕｜7 天没完成 → 计划真的变了（60 秒）——回答评审第 5 题

操作：对第 2 幕的行动点「没顾上」。

看点：页面立即出现「计划已调整」卡片：

```
为什么改：上一轮没顾上，先降低负担，把行动拆到能立刻开始的程度。
接下来怎么做：原行动 → 拆成 2 次，每次不超过 15 分钟；仍无法开始则只保留 1 次 10 分钟的最小动作。
```

数据可查：`adjustments` 集合记录了 before / after / reason / trigger，**第三次未完成会建议冻结目标周期**而不是继续催。

## 第 6 幕｜纠错与删除（30 秒）——回答评审第 6 题

操作：在记忆本里纠正一条记忆、或删除一条。

看点：页面显示原话来源；`auditLog` 记录纠正前后内容；删除后该条不再进入后续推演。

## 收尾（20 秒）：回答"怎么证明越来越准"

```
不看模型输出是否流畅，看三个可收集的指标：
1. 历史引用准确率 = 记忆本中被用户确认为正确的引用 / 全部引用
2. 理解摘要确认率 = 用户确认 / (确认 + 纠正)
3. 反馈后完成率变化 = 调整后下一周期的完成率 - 调整前
当前为 0 用户、0 数据 —— 我们不预设成绩，只保证指标可采集（metrics 云函数已就绪）。
```

## 现场被追问时的标准回答

| 追问 | 回答 |
|---|---|
| 为什么必须用 AI？ | 决策习惯、约束、红线、历史是组合输入，模板覆盖不了；同时我们承认 AI 的输出必须过结构校验与红线校验，不是任由模型发挥。 |
| 你的创新在哪？ | 同一用户的连续推演中，事实变更、红线、反馈会**改变**后续输出，且每一次改变都有可查记录（injectedMemoryIds / adjustments / auditLog）。 |
| 性格测评科学吗？ | 我们做的是标注为探索性的自编问卷，只用于调整行动建议的表达方式；标准化量表需要授权与信效度核查，已排到阶段 1。 |
| 记忆会不会记错？ | 每条记忆带来源与原话，可查看、纠正、删除；AI 推断一律标注待确认，且不得作为事实使用。 |
| 上线资格呢？ | 已确认深度合成类目仅对非个人主体开放，正在办理主体升级并准备模型服务商的算法备案材料（ADR-0003）。 |
